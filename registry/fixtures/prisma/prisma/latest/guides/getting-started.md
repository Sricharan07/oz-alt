What you will do

No matter which guide you choose, the flow is usually the same:

Define a database connection and data model in your Prisma schema.

Install Prisma CLI and Prisma Client.

Run prisma generate to create a type-safe client for your schema.

Create or introspect your database, then start sending queries from your application.
