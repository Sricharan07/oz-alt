# How to Create an Instant Voice Clone

In this tutorial, you will learn how to use the **Smallest AI** platform to create an **Instant Voice Clone** using a short audio sample. This process is quick and efficient, allowing you to generate high-quality voice clones in minutes.

# Creating an Instant Voice Clone

1️. **Go to the Smallest AI Platform**

* Navigate to **[smallest.ai](https://app.smallest.ai/dashboard/voice-cloning)** and click on **Create New**.
* In the modal that appears, select **Instant Voice Clone**.

![Voice Clone Setup](https://files.buildwithfern.com/smallest-ai.docs.buildwithfern.com/60f9ac68e761556450dbcfb459397215c82c3505bd9cb62e04a9bde4ef9959f2/products/waves/pages/images/ivc-image-1.png)

2️. **Upload Your Clean Reference Audio**

* Select a **short, high-quality** audio clip (5-15 seconds).
* Ensure the recording is **clear and noise-free** for the best results.
* Follow the recommended **[best practices](/v3.0.1/content/best-practices/vc-best-practices)** to maximize quality.

![Upload your clean reference audio](https://files.buildwithfern.com/smallest-ai.docs.buildwithfern.com/e0223e4d626748c73598a294f018448e50e3da2161eedc7f4150c71ed334826d/products/waves/pages/images/ivc-image-2.png)

3️. **Review Generated Testing Examples**

* The platform will process your reference audio and generate **sample outputs**.
* Listen to the test clips to verify the voice match.

![Testing Examples](https://files.buildwithfern.com/smallest-ai.docs.buildwithfern.com/cbb29c140a5a9d44a52ae78bccff90292a5c98554a74009b089d8ae21ef85dee/products/waves/pages/images/ivc-image-3.png)

4️. **Customize & Save Your Voice Clone**

* Fill in details like **Name, Tags, and Description** for your voice.
* Click **Generate** to store your cloned voice.

![Create Voice](https://files.buildwithfern.com/smallest-ai.docs.buildwithfern.com/8b015c5b13b20e3d868ae09cb54ea45f9613d437c4f77d2c61b026c0e8ba73c5/products/waves/pages/images/ivc-image-4.png)
